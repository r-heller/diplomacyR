# Colours for the seven Great Powers

A colourblind-safe palette, keyed by power name. The same seven colours
identify units, supply-centre ownership and every power-coded series in
the analysis plots, so a colour means the same thing everywhere in the
package.

## Usage

``` r
dp_palette()
```

## Value

A named character vector of hex colours.
