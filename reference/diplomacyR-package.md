# diplomacyR: Play, Simulate, and Analyse the Board Game Diplomacy

A complete engine for the strategic board game Diplomacy, covering the
standard seven-power pre-1914 European map. Provides a rules-accurate
simultaneous-movement adjudicator (hold, move, support, convoy, retreat,
and build phases) validated against the Diplomacy Adjudicator Test
Cases, a set of scriptable bots for automated play, batch simulation
with outcome analysis, and a comprehensive 'shiny' application for
interactive play and exploration. Board states and analyses render as
'ggplot2' objects.
